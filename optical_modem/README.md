# Optical Modem

Sistema de comunicación óptica pantalla-cámara.

## Estructura

- tx/: transmisor
- rx/: receptor
- common/: utilidades compartidas
- tests/: pruebas

## Setup

source venv/bin/activate

pip install -r requirements.txt

## Ejecutar TX

python tx/transmitter.py

## Ejecutar RX

python rx/receiver.py
